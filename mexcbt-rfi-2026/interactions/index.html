MEXCBTにおけるインタラクションの選定について

2026年9月28日
合同会社情報アクセシビリティ機構
代表社員　村田 真

要旨

MEXCBTでは、QTIで利用可能なインタラクションを網羅的に実装するのではなく、使用するインタラクションを明示的に制限すべきである。初期段階では、QTI 3 Basic認証レベルで必須とされる choiceInteraction、textEntryInteraction、extendedTextInteraction の三種類を基本とすることを提案する。

それ以外のインタラクションは、基本的な回答形式では適切に測定できない対象を測定するために必要であり、その便益が、測定上・アクセシビリティ上の不利益や、実装・検証・相互運用性・保守に伴うコストを上回ることが確認された場合に限って追加すべきである。

1. インタラクションは測定に対して中立ではない

CBTによる評価で優先すべきなのは、どのような問題を作ることができるかではなく、測定対象となる能力・特性を妥当に測定できるかである。受験者が問題内容を理解し正答を知っていても、インタラクションの操作方法を理解できない、又は適切に操作できないために誤答するのであれば、本来測定しようとしている能力とは異なる要因が測定結果に入り込む。これは、測定対象とは無関係な要因が結果に影響する問題（construct-irrelevant variance）である。

例えばArslanらは、同等の数学的内容を五つの異なるドラッグ・アンド・ドロップ形式で提示する実験を行い、インタラクションの設計の違いが受験者の成績及び解答方略に影響することを報告している。この研究からドラッグ・アンド・ドロップを一律に排除すべきだという結論が直接導かれるわけではないが、少なくとも、同じ内容を問うのであればインタラクションは何を使っても同じであるという前提は成立しない。

したがって、新しいインタラクションを採用する場合には、まず、選択式やテキスト回答といった基本的な回答形式では適切に測定できない何を、そのインタラクションによって測定できるのかを説明すべきである。紙ではできなかった問題を作れること、問題の種類が増えること、画面上で新しい操作ができること自体は、採用理由にはならない。学習意欲や集中の向上など、測定以外の教育上の便益を期待する場合にも、印象ではなく実証によってその便益を示す必要がある。

2. アクセシビリティ上の制約

高度なインタラクションは、一部の受験者にとって操作そのものが障壁となる可能性がある。例えばWCAG 2.2 Success Criterion 2.5.7 Dragging Movementsは、ドラッグ操作を使用する機能について、ドラッグ操作が不可欠である場合などを除き、ドラッグを必要としない単一ポインタによる操作手段を提供することをLevel AAで要求している。

したがって、ドラッグ・アンド・ドロップを採用する場合には、マウスでドラッグできるだけでは不十分である。ドラッグを用いない代替操作、キーボードによる操作、フォーカス管理、操作対象や状態の適切な伝達、支援技術との組合せ、拡大表示環境での動作を考慮した実装と検証が必要になる。

WCAG 2.2と同内容のISO/IEC 40500:2025は2025年9月に発行されており、JIS X 8341-3についても、この国際規格との一致規格とする方針で改正原案の作成が進められている。これから構築するMEXCBTでは、WCAG 2.2への対応を将来課題とするのではなく、当初からこれを前提としてインタラクションを選定・実装すべきである。この問題はドラッグ・アンド・ドロップだけに限定されず、図形操作や空間的位置関係に強く依存するインタラクションについても同様に検討する必要がある。

3. インタラクションの追加はシステム全体に影響する

インタラクションを一つ追加するコストは、CBT実行環境への実装だけではない。QTIをシステム間を接続する共通仕様として使用する場合、問題作成システム、検証システム、問題管理システム、CBT実行環境、解答収集、採点、アクセシビリティ試験、相互運用性試験、作問ガイドライン、問題作成者への教育、将来の互換性維持や保守に影響が及ぶ。

また、インタラクションをアクセシブルに実装するには、HTMLの意味構造、WAI-ARIAによる役割・状態・プロパティ、フォーカス移動、キーボード操作、状態変化の通知、アクセシブルな名前を適切に設計し、複数のブラウザや支援技術との組合せで検証する必要がある。インタラクションの種類を増やすほど、この実装・検証範囲は拡大する。

特定のCBT実行環境だけで動作する独自実装が生じれば、QTIを採用していても実質的な相互運用性は失われる。このため、インタラクションの追加は単に機能が一つ増えることではなく、システム全体の恒久的な複雑性や保守負担を増やす判断である。

4. QTI 3 Basicを出発点とする理由

1EdTechのQTI 3適合性・認証制度には、BasicとAdvancedという認証レベルが設けられている。Basicで必須とされるインタラクションは、次の三種類である。

  • choiceInteraction
  • extendedTextInteraction
  • textEntryInteraction

Advancedでは、これらに加えて、次のインタラクションが必須となる。

  • gapMatchInteraction
  • graphicGapMatchInteraction
  • hotspotInteraction
  • hottextInteraction
  • inlineChoiceInteraction
  • matchInteraction

ただし、BasicとAdvancedはQTI実装の適合性・相互運用性の水準を規定するものであり、特定のテストで使用すべきインタラクションの集合を定めるものではない。Advancedで必須とされているからといって、そのインタラクションをMEXCBTでも当然に提供すべきことを意味しない。

この点は、米国の州主導コンソーシアムであるSmarter Balancedの実例からも確認できる。2024–25 Technical Reportに示される問題群では、選択式、Hot Text、短答、Match Interaction、複数選択、長文記述、数式回答、表形式などが用いられており、QTI 3 Advancedで必須とされるインタラクションの集合をそのまま採用しているわけではない。

したがって、QTI仕様上の認証レベルと、MEXCBTで必要な問題形式は分けて考えるべきである。その上で、選択、短答、長文記述という基本的な回答形式を実現しつつ、CBT実行環境、問題作成システム、アクセシビリティ検証、相互運用性試験の範囲を限定できるQTI 3 Basicの三種類を、初期段階の出発点とすることには合理性がある。

5. MEXCBTへの提案

次期MEXCBTでは、初期段階で使用可能なインタラクションを、QTI 3 Basic認証レベルで必須とされる次の三種類を基本として明示的に制限することを提案する。

  • choiceInteraction
  • textEntryInteraction
  • extendedTextInteraction

英語スピーキングにおける音声回答のように、測定対象となる能力・特性のために基本的な回答形式では代替できないものについては、以下の基準を満たすことを確認した上で、個別に追加すべきである。

Basic以外のインタラクションを追加する場合には、少なくとも次の事項を事前に明らかにすべきである。

  1. 測定対象
    そのインタラクションによって測定しようとする能力・特性は何か。

  2. 必要性
    選択式又はテキスト回答では、なぜその能力・特性を適切に測定できないのか。

  3. 測定上・教育上の便益
    測定の妥当性又は精度がどのように改善するのか。測定以外の教育効果を期待する場合には、その効果は何か。

  4. 測定上の副作用
    インタラクションの操作能力や画面操作への習熟が結果に混入しないか。

  5. アクセシビリティ
    キーボード、代替操作、支援技術を含め、対象受験者が適切に操作できるか。

  6. 相互運用性
    特定のCBT実行環境に依存せず、複数のQTI実装間で同じ問題を交換・実行できるか。

  7. 実装・検証・保守コスト
    問題作成システム、問題管理システム、CBT実行環境、採点、解答収集、アクセシビリティ試験、相互運用性試験を含むシステム全体への影響はどの程度か。

最終的に問うべきなのは、そのインタラクションを追加することによって得られる測定上・教育上の便益が、測定上・アクセシビリティ上の不利益や、実装・検証・相互運用性・保守に伴うコストを上回るかである。これを示せないインタラクションは、使用可能とすべきではない。
